⛸ Симулятор финала Гран-при

Создайте свой сценарий отбора: шесть этапов, четыре дисциплины, актуальные заявки и расчёт состава финала.

Как пользоваться

  1. Выберите вид и этап Гран-при.
  2. Нажимайте на участников в порядке их предполагаемых мест.
  3. Перетаскивайте участников, чтобы изменить расстановку.
  4. Посмотрите, кто проходит в финал по вашему прогнозу.

Результаты моделирования не являются прогнозом вероятностей или гарантией квалификации. Составы: октябрь 2026 года. Гран-при Франции: официальные итоговые результаты 23–25 октября, этап зафиксирован.

Выберите вид

Списки по этапам уже заполнены по предоставленным заявкам ISU за октябрь 2026 года. Для замен можно добавить участника непосредственно в нужном этапе через пункт «Добавить замену». Более поздние изменения заявок могут не учитываться.

Этапы

Баллы: одиночное — 15, 13, 11, 9, 7, 5, 4, 3; пары/танцы — 15, 13, 11, 9, 7, 5

⠿ Перетащите строку за номер места для перестановки. Для тай-брейка можно внести итоговую сумму судейских баллов рядом с участником.

Выберите участников по порядку мест

Нажимайте на имена: первое нажатие — 1-е место, второе — 2-е и так далее. Затем можно перетаскивать строки для изменения порядка.

Оба режима заполняют только свободные места и сохраняют вручную введённые результаты. В случайном прогнозе даже фаворит может проиграть. Уже зафиксированные этапы не меняются.
